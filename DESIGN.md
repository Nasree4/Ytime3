# YTime2 Web visual system

Identity from the supplied Android app: YTime2 name and vivid pink. This web adaptation uses a bright workday surface, Thai-first type, and a simple information hierarchy for quick attendance actions.

- Base: white panels on pale blue-gray `#f6f8fb`; ink `#202b3b`; muted `#718092`.
- Brand: YTime2 pink `#e91367`; darker action state `#c60d56`.
- Supporting cues: blue for location, warm amber for guidance, green for connected status.
- Typography: IBM Plex Sans Thai with Tahoma fallback. Large greeting, compact operational labels.
- Layout: fixed desktop navigation, mobile drawer, broad action area, responsive panels.
- Interaction: camera and location only activate after user action; alerts are explicit; destructive external actions require form submission.
